## ✨ Bot làm được những gì?

* 📢 **Báo tất cả bài đăng mới:** Tự động theo dõi các Fanpage trường, Khoa, CLB mà bạn thêm vào và bắn thông báo về Telegram ngay khi có bài mới.
* 🔥 **Tự động lọc Điểm Rèn Luyện (ĐRL):** Tích hợp AI (Google Gemini) để đọc hiểu bài viết lẫn chữ trên ảnh Poster, tự động gắn nhãn **`[ĐIỂM RÈN LUYỆN]`** cho các sự kiện có cộng điểm.
* 🔍 **Quét mã QR & Bình luận:** Tự động quét ảnh giải mã QR và lục comment để lấy sẵn link điền Google Form hoặc nhóm Zalo cho bạn.
* 🔔 **2 chế độ nhận tin:** Bạn có thể chọn *Nhận tất cả bài viết mới* hoặc *Chỉ nhận bài có Điểm rèn luyện* bằng lệnh `/drl`.
* 📌 **Tủ lưu trữ:** Bấm nút **Lưu bài viết** để cất các sự kiện quan trọng vào tủ (`/saved`) và xem lại bất cứ lúc nào.

## 🎮 Các lệnh sử dụng trên Bot

| Lệnh | Chức năng |
| :--- | :--- |
| `/menu` | 🎛️ Mở bảng điều khiển chính |
| `/list` | 📋 Xem danh sách các trang đang theo dõi |
| `/add` | ➕ Thêm trang mới vào danh sách theo dõi |
| `/scan` | ⚡ Kiểm tra bài viết mới ngay lập tức |
| `/latest` | 🆕 Xem lại bài vừa đăng gần nhất của các trang |
| `/drl` | 🔔 Đổi chế độ nhận thông báo |
| `/saved` | 📌 Mở tủ xem lại các bài viết đã lưu |
| `/help` | 📖 Xem hướng dẫn lấy link RSS từ Facebook |
